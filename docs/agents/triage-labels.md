# Triage Labels

## 分诊角色

| 技能角色 | GitHub 标签 | 含义 |
| --- | --- | --- |
| needs-triage | needs-triage | 等待维护者评估 |
| needs-info | needs-info | 等待补充信息 |
| ready-for-agent | ready-for-agent | 规格明确，可交给 agent 实现 |
| ready-for-human | ready-for-human | 需要人类实现或决策 |
| wontfix | wontfix | 不予处理 |

技能提到分诊角色时，使用对应标签。
切换分诊状态时替换旧状态标签，保留类别标签。

## 常用类别

| 标签 | 用途 |
| --- | --- |
| bug | 功能错误或回归 |
| enhancement | 新功能或功能改进 |
| documentation | 文档改动 |
| question | 使用问题或讨论 |
| maintenance | 依赖、工具链、重构及日常维护 |
| performance | 性能、延迟或资源消耗 |
| testing | 测试和验证体系 |
| security | 不含敏感细节的安全加固工作 |

敏感漏洞、凭据和可利用细节交由维护者确定私密处理渠道，
不直接发布到公开 Issues。

## 其他标签

保留 GitHub 常用标签：
`duplicate`、`invalid`、`good first issue`、`help wanted`。

Wayfinder 使用：
`wayfinder:map`、`wayfinder:research`、`wayfinder:prototype`、
`wayfinder:grilling`、`wayfinder:task`。

类别标签与分诊标签独立，可组合使用。
沿用已配置标签；新增或重命名标签须得到维护者批准。
